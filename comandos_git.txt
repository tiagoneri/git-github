git init.            -> cria um repo git na pasta atual
git status           -> mostra o status do trabalho
git add nome_arquivo -> adciona arquivo para ser commitado
git commit -m "msg"  -> faz commit do que estava para ser commitado
git log              -> mostra todos o histórico de commit


##Fluxo de TRABALHO
1. criar diretório (pasta) do projeto
2. iniciar git dentro do diretório
3. edita ou cria arquivos
4. git status
5. git add "nome do arquivo"
6. git commit -m "mensagem"
7. git status
8. volta para o passo 3
